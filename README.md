# Bùi Minh Cường — Portfolio

Trang portfolio cá nhân giới thiệu Bùi Minh Cường, sinh viên năm nhất ngành Kỹ thuật phần mềm tại Đại học FPT TP. Hồ Chí Minh.

## Xem trang web

- **Portfolio:** https://minhnoxdev.github.io/My-Portfolio-/
- **Mã nguồn:** https://github.com/MinhNoxDev/My-Portfolio-

GitHub Actions tự động triển khai trang lên GitHub Pages mỗi khi có thay đổi trên nhánh `main`. Lần triển khai đầu tiên có thể mất vài phút.

## Nội dung

- Giới thiệu và thông tin học tập.
- Kỹ năng lập trình đã học và đang học.
- Quá trình học tập từ tiểu học đến Đại học FPT.
- Chứng chỉ MOS Word và MOS Excel.
- Ảnh cá nhân, hiệu ứng tương tác và nút chuyển giao diện sáng/tối.
- Thông tin liên hệ qua email.

## Công nghệ

- HTML
- CSS
- JavaScript
- Google Fonts: Montserrat và DM Mono

## Chạy trên máy cá nhân

Mở thư mục dự án bằng Visual Studio Code và chạy `index.html` với tiện ích Live Server, hoặc khởi động máy chủ tĩnh bằng Python:

```bash
python -m http.server 8000
```

Sau đó mở <http://localhost:8000> trong trình duyệt.
